# Artayb Analytics Studio

Artayb Analytics Studio is an interactive data analysis and data-cleaning web application built with Python, Pandas, and Streamlit.

The application allows users to upload CSV files, explore datasets, check data quality, visualize numeric data, clean missing values, and download the cleaned dataset.

## Live App

🔗 https://artayb-analytics-studio.streamlit.app/

## Features

- Upload CSV datasets
- Preview the first 5 records
- Select and explore specific columns
- View dataset rows, columns, and column names
- Check missing values
- View data types
- Generate statistical summaries
- Visualize numeric data with charts
- Calculate a data-quality score
- Get smart insights about the dataset
- Fill numeric missing values with the column mean
- Remove rows containing missing values
- Compare data before and after cleaning
- Download the cleaned dataset

## Technologies Used

- Python
- Pandas
- Streamlit
